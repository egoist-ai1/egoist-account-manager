# Codex Account Manager

> Текущий project-local handoff: [`STATUS.md`](./STATUS.md).

Codex Account Manager by Egoist AI — локальная Windows-панель для управления несколькими Codex ChatGPT-профилями и Anti-Gravity Beta-профилями. Приложение хранит профили на текущем ПК, показывает лимиты, помогает выбрать аккаунт и безопасно переключает активный профиль.

> Неофициальный community-инструмент. Проект не связан с OpenAI. Используй его только с аккаунтами, которыми владеешь или которыми имеешь право управлять.

## Коммерчески чистая реализация

Приложение развивается как оригинальный Electron/TypeScript-продукт. Внешние проекты можно использовать только как поведенческие референсы: код, брендинг, installer/updater-метаданные, иконки и UI-тексты из несовместимых лицензий не копируются.

## Возможности

- Панель нескольких Codex ChatGPT-профилей.
- Авторизация через ChatGPT browser, device code, OpenAI API key или enterprise access token.
- Отображение 5-часового и недельного лимита со временем сброса.
- Ручное и автоматическое обновление лимитов.
- Автообновление каждые 3 минуты без принудительной ротации credentials и ремонт проблемного профиля прямо из карточки.
- Проверяемое транзакционное переключение: закрытие точного Codex Desktop-пакета, активация, перезапуск, runtime identity proof и автоматический rollback.
- Честный «План продолжения»: следующий профиль выбирается только из защищённых входов со свежими известными лимитами; stale/unknown данные не превращаются в ложные `0%`.
- Теги, избранное, архив профилей и компактная история лимитов.
- Overview, Accounts, Activity и Settings, карточки аккаунтов, журнал фаз и командная палитра `Ctrl+K`.
- Повторная авторизация сохранённого профиля без дублей.
- Только официальные способы добавления Codex-профиля: ChatGPT browser, device code, OpenAI API key и Enterprise access token; произвольный импорт `auth.json` не предлагается.
- Last-known-good DPAPI-vault продолжает хранить и проверять профиль, даже если Codex Desktop временно вышел из аккаунта.
- Автоматическая проверка последнего стабильного GitHub Release при запуске, локальные crash-отчёты и SHA256-контроль артефактов.
- Живой Windows tray показывает крупный точный остаток фактически ограничивающего подтверждённого окна в DPI-aware значке 16/20/24/32 px. При наведении без клика появляется пассивная полупрозрачная WhyX-панель 252×144 px с активным Codex-профилем, одной актуальной шкалой и точным временем сброса; отсутствующая пятичасовая квота больше не дублирует недельную. Системная серая tooltip отключена, а клик по-прежнему открывает отдельную рабочую панель. Авторизация, лимит, перезапуск, подтверждение и rollback приходят только в очередь внутри Manager с коротким настраиваемым звуком; Windows-toast удалены.
- Непрерывная сетка аккаунтов: 9 полностью видимых карточек в стандартном окне и внутренний скролл для остальных.
- Настраиваемая рабочая папка Codex.
- Зашифрованный экспорт/импорт `.cam-export` для переноса профилей.
- Frameless Windows-интерфейс, установщик и portable-сборка.

## Безопасность

- Локальный auth-материал хранится на текущем Windows-ПК и шифруется через Electron `safeStorage` / Windows DPAPI. Если защищённое хранилище недоступно, приложение не создаёт новый plaintext vault.
- Новые `.cam-export` защищены паролем через `scrypt` и AES-256-GCM; предыдущие форматы поддерживаются только для импорта.
- После расшифровки экспорт содержит чувствительные авторизационные данные. Храни его приватно и удаляй временные копии после переноса.
- Приложение не выводит токены и сырой `auth.json` в интерфейс.
- Управляемые Codex-профили хранят auth bundle только в DPAPI-защищённом vault; предыдущий bundle для rollback также запечатан и проверяется по SHA-256.
- Операции одного провайдера и общего `CODEX_HOME` сериализуются, а незавершённая транзакция восстанавливается при следующем запуске.

## Скачать

Открой последний GitHub Release и выбери один из файлов:

- `Codex-Account-Manager-Setup-3.1.4.exe` — one-click установщик Windows.
- `Codex-Account-Manager-3.1.4.exe` — portable-сборка без установки.

Для проверки целостности используй `SHA256SUMS-3.1.4.txt` и сравни SHA256 файла.

## Автообновление

Версия 3.1.4 через несколько секунд после запуска обращается к публичному GitHub Releases API и сравнивает текущий semver с последним стабильным релизом. Если версия новее, Manager показывает компактную плашку внутри приложения; кнопка открывает только страницу релиза `egoistgorbachev/codex-account-manager`. Неподписанный EXE не скачивается и не запускается скрыто. При установке поверх прежней версии локальные профили, SQLite и DPAPI-vault сохраняются.

Предыдущие релизы ветки `1.x` можно оставить как rollback-сборки.

## Разработка

```powershell
pnpm install
pnpm run typecheck
pnpm run lint
pnpm run test:node
pnpm run build:dir
pnpm run smoke
pnpm run build
```

Приложение собрано на Electron, React, TypeScript, Vite и `electron-builder`.

`pnpm run test:node` пересобирает `better-sqlite3` для Node, а `pnpm run build` — для Electron. Эти режимы намеренно разделены: после installer-сборки снова запусти `pnpm run test:node` перед unit-тестами.

## Важные заметки

- Основная целевая платформа - Windows 11.
- Каждый переключаемый профиль создаётся официальным входом в отдельном manager-owned `CODEX_HOME` с file-backed cache. Существующий `keyring`, `auto`, `ephemeral` или произвольный `auth.json` автоматически не извлекается; пользовательский `config.toml` Manager не изменяет.
- EXE пока не подписаны коммерческим Windows-сертификатом, поэтому SmartScreen может показать предупреждение; сверяй SHA256 перед запуском.
- Anti-Gravity помечен как Beta: приложение показывает источник и достоверность квот; расширенный импорт credential-данных требует явного подтверждения и не выводит секреты в интерфейс или логи.
- Не публикуй `auth.json`, `.cam-export`, локальные базы данных и сгенерированные release-бинарники в исходниках репозитория.
