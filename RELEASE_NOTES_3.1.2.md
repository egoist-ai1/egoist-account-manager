# Codex Account Manager 3.1.2

## Процент виден прямо на панели задач

- Значок теперь содержит отдельные чёткие представления для Windows DPI 100%, 125%, 150% и 200%.
- Крупные цифры показывают точный минимальный остаток между лимитами 5 часов и недели; `!`, `~` и `—` честно обозначают ошибку, устаревание и отсутствие данных.
- Системная серая tooltip удалена.

## Пассивная WhyX-панель при наведении

- Через 240 мс после наведения появляется полупрозрачная панель с активным аккаунтом, подпиской, обоими лимитами и свежестью данных.
- Панель не перехватывает мышь, не получает фокус, не содержит кнопок и сама исчезает после ухода курсора.
- Позиция учитывает нижнюю, верхнюю и боковые панели задач, несколько мониторов и отрицательные координаты.
- Клик по значку сохраняет отдельную рабочую панель с действиями.

## Проверенная сборка

- TypeScript, ESLint, 336 Node/integration tests, 15 UI smoke checks, multi-DPI native-image decode, ASAR parity и packaged startup прошли.
- Текущая сборка не подписана Authenticode; SmartScreen может показать предупреждение. Сверяйте SHA-256 с `SHA256SUMS-3.1.2.txt`.
