# Codex Account Manager 3.0.10

## Что изменилось

- Главный экран полностью помещается в стандартное окно `1460×900`: вертикальный скролл и обрезание нижних карточек устранены, а рабочая поверхность занимает высоту до нижнего отступа.
- В «Последней операции» появился понятный маршрут переключения: защищённый снимок, перезапуск точного дерева Codex и проверка фактической личности.
- Мастер «Добавить Codex» теперь сразу предлагает два быстрых сценария: использовать текущую локальную сессию либо выбрать `auth.json`.
- Текущая file-backed сессия проверяется официальным app-server, получает identity и лимиты, после чего сохраняется в DPAPI-vault. Исходный `auth.json` не изменяется и не удаляется.
- При `keyring`, `auto` или `ephemeral` приложение честно показывает режим «только мониторинг»: публичного способа экспортировать такой секрет нет, поэтому для переключаемого профиля предлагается новый официальный вход.
- File import получил защиту от слишком больших файлов, ссылок, каталогов и изменения файла во время чтения; содержимое не проходит через renderer, журнал, clipboard или уведомление.
- Antigravity-вход упрощён до трёх основных карточек: Google OAuth, локальная IDE и JSON; диагностика видна сразу, редкое восстановление отделено.
- Внутренние уведомления показывают подписанные этапы. Windows toast получил attribution, действие «Открыть менеджер» и отдельное подтверждение импорта.
- Ошибка подключения к локальному хранилищу теперь показывается компактной строкой и больше не растягивает экран настроек; сырой системный текст скрыт из интерфейса и доступен только через «Журнал».

## Важное ограничение

Один file-backed `auth.json` не должен независимо обновляться несколькими параллельными процессами. Manager сохраняет текущую сессию как защищённый snapshot и сериализует операции Codex; keyring-секреты не извлекаются обходным путём.

## Распространение

EXE пока не подписаны Authenticode. Версия предназначена для локальной/manual установки после проверки `SHA256SUMS-3.0.10.txt`; публичное автоматическое обновление остаётся fail-closed до подписанного релиза.
