# Codex Account Manager 3.0.4

## Главное

- Автообновление работает каждые 3 минуты и больше не вращает credentials при каждом quota-запросе.
- Ошибка `Codex profile is not authenticated` теперь распознаётся как потеря provider-сессии, а не остаётся ложным зелёным состоянием.
- Проблемный профиль не удаляется: кнопка «Починить» проверяет vault, повторяет обновление и при необходимости открывает device-code вход в тот же аккаунт без дубля.
- Неуспешная проверка больше не перезаписывает последний подтверждённый DPAPI-vault; последний корректный снимок лимитов сохраняется.
- Overview и Activity переработаны в компактную операционную панель: два окна лимитов, freshness/source, состояние защиты, умный резерв, KPI и единый журнал переключений.
- Production renderer больше нельзя подменить через `ELECTRON_IS_DEV` или package-конфигурацию из текущей папки.

## Что означает «вход сохранён»

Это подтверждает наличие локального зашифрованного auth bundle. Провайдер всё равно может отозвать refresh token, запросить MFA или завершить серверную сессию. В таком случае профиль и его история остаются в Manager, а «Починить» восстанавливает официальный вход на месте.

## Безопасная проверка

Release-gate не переключал и не закрывал установленный пользовательский Codex. Переключения проверены на синтетическом `CODEX_HOME`; exact packaged EXE запускался только с отдельным пустым `CAM_USER_DATA_DIR` и завершался по своему проверенному пути.

## Ограничение доставки

EXE пока не подписаны Authenticode. Версия готова для локальной/manual установки с проверкой `SHA256SUMS-3.0.4.txt`; публичное автоматическое обновление остаётся отключённым до signed release.
