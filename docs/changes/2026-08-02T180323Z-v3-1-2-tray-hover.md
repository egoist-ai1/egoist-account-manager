# 3.1.2 readable multi-DPI tray and passive WhyX hover

- Date: 2026-08-02T18:03:23Z
- Type: release-candidate
- Status: complete with native-runtime follow-up
- Related: `docs/releases/3.1.2.md`, `CTX-009`

## Why

The 3.1.1 tray surface exposed quota information but its single small glyph and native gray Windows tooltip were not readable or visually consistent at taskbar scale. The selected design requires an exact percentage on the persistent icon and a passive branded explanation on hover.

## What changed

- Replaced the single-scale glyph with pixel-aligned 16/20/24/32 px NativeImage representations for Windows DPI 100/125/150/200%.
- Made exact digits dominant and preserved truthful non-percent states `!`, `~` and `—` without spending scarce 16px space on a logo or percent sign.
- Removed the native tooltip and added a separate translucent 340×196 WhyX hover window with a 240 ms dwell and 120 ms exit delay.
- Kept the hover surface non-focusable, click-through, action-free and independent from the existing click popup/context menu.
- Added edge-aware positioning for all taskbar sides, nearest work area and negative-coordinate displays.
- Advanced exact local version and artifacts to 3.1.2; no GitHub publication, host install, real-account switch or active Codex manipulation occurred.
