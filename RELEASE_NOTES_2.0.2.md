# Codex Account Manager 2.0.2

- Профили проходят проверку identity до чтения лимитов и до подтверждения авторизации.
- После обновления токенов зашифрованный vault синхронизируется с актуальным `auth.json`.
- Перед автоматическим восстановлением профиля создаётся backup предыдущего локального auth-файла.
