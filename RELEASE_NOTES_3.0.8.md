# Codex Account Manager 3.0.8

## Что изменилось

- Код устройства автоматически копируется до открытия официальной страницы входа. В окне Manager его можно скопировать повторно; после выбора аккаунта остаётся нажать `Ctrl+V`.
- Если код остаётся в буфере неизменным, Manager удаляет его через 15 минут или при закрытии приложения. Пользовательское содержимое буфера никогда не перезаписывается при очистке.
- Карточки аккаунтов яснее показывают тариф, состояние сохранённого входа, свежесть данных и остаток каждого окна лимитов. Восстановление запускается компактной кнопкой-ключом без обрезанного текста.
- Успешная повторная авторизация теперь атомарно сбрасывает прежний сбой обновления даже при временно недоступном первом запросе квоты: сохранённый вход больше не соседствует с ложной кнопкой восстановления.
- Окно профиля показывает все шесть действий сразу — активацию, обновление, проверку входа, повторную авторизацию, папку и удаление — без скрытого раздела и внутреннего скролла; `Escape` закрывает окно и возвращает фокус на исходную карточку.
- Overview заполнен полезными сигналами: резервные профили, защищённые входы, свежие квоты, доступность app-server и ближайший сброс.
- Activity объясняет назначение четырёх стадий переключения и визуально отделяет проверку, применение auth, запуск Codex и подтверждение аккаунта или безопасный откат.

## Безопасность авторизации

Manager использует только официальный device-code URL и локальный Codex app-server. Приложение не имитирует нажатия клавиш в чужом окне: это исключает вставку кода не в тот браузер или поле. Auth-профили остаются в локальном DPAPI-vault, а switch по-прежнему подтверждает фактическую identity и откатывает неуспешную транзакцию.

## Распространение

EXE пока не подписаны Authenticode. Версия предназначена для локальной/manual установки с обязательной проверкой `SHA256SUMS-3.0.8.txt`; публичное автоматическое обновление остаётся fail-closed до подписанного релиза.
