# Codex Account Manager 3.1.6 — preview

3.1.6 пока не опубликована как бинарный релиз. Кандидат прошёл исходные, UI, package и startup-проверки, но чистая Windows Sandbox заблокировала неподписанный EXE политикой Smart App Control до запуска приложения. Публичной стабильной версией остаётся [3.1.5](https://github.com/egoistgorbachev/codex-account-manager/releases/tag/v3.1.5).

## Что подготовлено

- ближайший реальный сброс среди защищённых неархивных профилей;
- корректная работа списка с 10+ аккаунтами;
- карточки и компактный режим;
- сортировка по активному профилю, готовности, подписке, остатку, reset и свежести;
- нейтральное недоступное состояние Antigravity с подсказкой «В разработке»;
- повторная полировка типографики, плотности, focus/hover и адаптивной раскладки;
- новый публичный README с обезличенными скриншотами.
