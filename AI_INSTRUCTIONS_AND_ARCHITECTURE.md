## 1. Назначение и контекст проекта

**Account Manager EGO** — это высоконадежное настольное приложение для Windows 10 и Windows 11 (x64), предназначенное для автономного управления, балансировки квот и бесшовного переключения между множеством аккаунтов двух ведущих систем генерации кода:
1. **OpenAI Codex CLI / Desktop**: Управление CLI и десктопными сессиями (ChatGPT подписки Plus/Pro/Team/Enterprise, прямые API-ключи, OAuth-сессии).
2. **Google Antigravity IDE**: Управление квотами и аккаунтами Google (OAuth 2.0 PKCE, восстановление резервных копий профилей).

### Основная ценность для пользователя:
- Устранение блокировок работы при исчерпании лимитов генерации кода.
- Умный алгоритм выбора наименее нагруженного аккаунта (smartSelection).
- Мониторинг оставшихся запросов и таймеров до сброса лимита в реальном времени.
- 100% локальное шифрование авторизационных данных через Windows DPAPI.
- Переключение в 1 клик с автоматическим сохранением несохраненного контекста и штатным перезапуском процессов.

## 3. Скандинавский дизайн-стандарт «Lagom» (ux-ui-agent-skills)

Весь интерфейс подчиняется строгим законам эргономики и минимализма:
1. **Строгая триколор-палитра**:
   - Фон (Void/Surface): чистый черный #000000, карточки #050507, при наведении #090a0f.
   - Текст и контуры: чистый белый #ffffff, приглушенный #a1a1aa, тонкие границы gba(255, 255, 255, 0.08).
   - Фирменный акцент (Electric Violet): #7c3aed (основной), #8b5cf6 (яркий), #c084fc (светящийся).
   - Красный цвет тревоги (Alert Red): #ef4444 / #f87171 — **СТРОГО** зарезервирован для ошибок, сбоев авторизации (has-error), протухших токенов и критического остатка квоты (<= 10%). Никаких посторонних красных элементов!
2. **Типографика Unbounded**:
   - Переменная гарнитура @fontsource-variable/unbounded подключена глобально как ar(--font-display).
   - Крупные метрики процентов лимитов (15px bold Unbounded), заголовки с отрицательным трекингом (-0.02em), контрастные моноширинные таймеры.
3. **Лимиты высокой контрастности**:
   - Полосы прогресса имеют высоту **7px** с градиентным неоновым заполнением и мягким свечением (ox-shadow: 0 0 10px rgba(147, 51, 234, 0.5)).
   - Четкие бейджи таймеров с иконкой часов Clock в фиолетовом контуре.
4. **Компактность карточек**:
   - Внутренние отступы 10px 14px, сжатые межстрочные интервалы 6px, компактные кнопки высотой 26px. Карточки на ~30% ниже стандартных без потери читаемости.
5. **Anti-Slop & Zero Emoji**:
   - Запрещены эмодзи. Используются векторные иконки Lucide с currentColor.
   - Никаких маркетинговых штампов («elevate, seamless, supercharge»). Краткие, точные инженерные термины.

## 5. Механика работы с процессами и права администратора

### Штатное закрытие и сохранение контекста:
1. При переключении аккаунта Codex или Antigravity вызывается windowsDesktopLifecycleService.ts.
2. Первым шагом процесс запрашивает мягкое завершение через Windows Message WM_CLOSE главного окна процесса. Это заставляет Codex сохранить черновики кода, активный буфер и историю сессии в SQLite.
3. Если процесс не завершился за отведенный таймаут (2.5 сек), вызывается штатная остановка дочерних узлов дерева (	askkill /T).
4. Если процесс требует повышенных привилегий, вызывается нативный вызов через elevated helper, гарантируя, что ни один процесс не зависнет с кодом ошибки EPERM.
5. После безопасного завершения подменяется авторизационный токен в защищенном хранилище uth.json / DPAPI vault.
6. Вызывается запуск процесса с новым профилем и валидация личности через app-server. В случае сбоя выполняется 100% атомарный откат (rollback) на предыдущий аккаунт.
