# Codex Account Manager 2.0.0

## Главное

- Единый финальный Windows-релиз с NSIS-установщиком, portable EXE, `latest.yml`, blockmap и SHA256-контрольными суммами.
- Управление локальными Codex-профилями с защищённым Windows vault, ручным подтверждением переключения и безопасной рекомендацией следующего профиля.
- Прозрачные состояния лимитов: остаток, время сброса, свежесть данных, история и ручное обновление.
- Командная палитра, история действий, диагностика, crash-отчёты и обновление через GitHub Releases.

## Безопасность

- Внешние ссылки на уровне IPC принимаются только по HTTPS, а main process дополнительно ограничивает их проверенным allowlist.
- Локальная сборка без сертификата остаётся работоспособной, но приложение явно сообщает, что EXE не подписан Windows-сертификатом.
- Не публикуй `auth.json`, `.cam-export`, SQLite-базы, логи или профили вместе с артефактами релиза.
