## Предыдущий цикл RC3

Продукт: Квессер / Kvesser. Рабочая версия: 3.2.0-rc.3 (локальная сборка Windows x64). Исходная точка RC3 — `a1fcf7a` в ветке `codex/egoist-3-2`. Последняя стабильная версия в `origin/main` — 3.1.10 / `d315ba1`.

Пользователь выбрал плотную таблицу и раздельные уровни подтверждения. Codex probe не доказывает Desktop identity; неизвестный runtime оставляет применённый профиль и snapshot, блокируя automatic switch.

Доставка в `release/3.2.0-rc.3` включает portable и установщик с манифестом владения файлами. Идентификатор приложения и формат хранилища совместимы с предыдущими версиями.

В RC3 переключение Antigravity выбирает запущенное приложение или подходящую установленную версию. Antigravity использует Windows Credential Manager, а для Antigravity IDE дополнительно обновляется SQLite выбранного профиля. Квессер подтверждает запуск по окну нового процесса, хранит зашифрованный снимок и проверяет аккаунт по локальному API, когда может установить его принадлежность процессу.
