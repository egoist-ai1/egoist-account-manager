# Codex Account Manager 2.1.0

- Быстрый one-click Windows installer без выбора папки установки.
- Обычное обновление заменяет предыдущую версию с тем же `appId`, не удаляя сохранённые аккаунты и зашифрованный vault.
- Экран пустой платформы и визуальные стили стали чище и предсказуемее.

> Установщик запускается в контексте текущего пользователя. Это позволяет автообновлениям работать без постоянного запроса UAC и не требует прав администратора.
