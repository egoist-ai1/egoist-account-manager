# Codex Account Manager 3.0.5

## Главное

- Настройки больше не накладываются друг на друга: обе раскрываемые секции занимают реальную высоту и прокручиваются внутри рабочей области.
- Стандартное окно увеличено до `1360×800`. В нём полностью помещаются девять карточек аккаунтов; остальные доступны обычным внутренним скроллом без пагинации по шесть.
- Карточки стали читаемее: тариф и статус входа видны сразу, остаток лимита визуально приоритетен, а обновление, повторная авторизация, ремонт, детали и переключение доступны одновременно.
- Activity получила более крупный шрифт, компактные KPI, устойчивый маршрут проверки и аккуратный журнал без пересечений текста с линиями и анимацией.
- Уведомления Windows подтверждают успешное переключение, сообщают о сбое и предупреждают при остатке подтверждённого лимита 10%. Клик по уведомлению открывает Manager.
- Новая чистая иконка без текстурного шума используется в окне, tray, ярлыках, installer и Windows toast. Репозиторий хранит SVG-источник и воспроизводимую сборку PNG/ICO.

## Надёжность

- UI-регрессия проверяет раскрытые Settings, отсутствие пересечений Activity, три колонки Accounts, внутренний скролл и новый размер окна в изолированном Electron-профиле.
- Проверки не запускают switch и не закрывают пользовательский Codex.

## Доставка

EXE остаются без Authenticode. Версия предназначена для локальной/manual установки с проверкой `SHA256SUMS-3.0.5.txt`; публичное автоматическое обновление остаётся fail-closed до подписанного релиза.
