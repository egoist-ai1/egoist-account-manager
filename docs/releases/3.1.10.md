# Account Manager EGO 3.1.10

Версия исправляет сохранение идентичности профилей, синхронизацию Antigravity, обновление квот и локальную установку. Статус выполненных проверок указан ниже.

<a id="codex"></a>
## Codex: идентичность и сохранение авторизации

- Сопоставление профиля учитывает учётную запись провайдера, workspace и fingerprint авторизации. Совпадения одного email недостаточно для подмены другого workspace.
- Для профилей API key проверяется fingerprint ключа. Другой ключ не присваивается существующему профилю только из-за совпадения режима авторизации.
- Пассивное чтение состояния и квот не запрашивает принудительное обновление токена. Обновление зашифрованного vault допускается после проверки идентичности.
- Блокировки операций и очистка временного состояния защищают синхронизацию, чтение квот и переключение от пересечения. Ошибка проверки профиля не закрепляет чужую авторизацию в vault.

<a id="antigravity"></a>
## Antigravity: синхронизация и достоверные квоты

- Устранён цикл, при котором построение списка профилей повторно запускало синхронизацию и чтение квот.
- Токен из глобального состояния IDE используется только для соответствующего аккаунта. Глобальный токен другого аккаунта не перезаписывает выбранный профиль.
- Неизвестные, пустые и null-значения квоты остаются неизвестными и не обозначаются как безлимитные в карточках аккаунтов. Значение `remainingFraction: 0` сохраняет смысл реального нулевого остатка.
- Ограничение времени охватывает запрос и чтение тела ответа; зависшие запросы отменяются, а обработка следующих источников может продолжаться.
- God Mode не включается автоматически при открытии, синхронизации или переключении профиля.
- Окна добавления Codex и Antigravity закрываются по Escape через существующий обработчик закрытия; закрывается только верхний диалог.

<a id="processes"></a>
## Antigravity: точная работа с процессами

- Распознаются `Antigravity.exe` и `Antigravity IDE.exe`.
- Завершение ограничено точным путём установленного приложения и его дочерними процессами. Общая команда остановки всех процессов с именем `language_server` удалена.
- Перед остановкой проверяется принадлежность PID исходному процессу. Ошибка проверки или остановки не считается успешным освобождением профиля.
- Повторный запуск после неудачной остановки не продолжается. Исправлен путь очистки служебных lock-файлов второго профиля.

<a id="tray"></a>
## Tray и режим приватности

- Фоновое обновление tray учитывает активные профили обеих платформ, с отдельной проверкой возраста данных.
- Режим приватности скрывает идентификаторы также в подсказках popover и пунктах умного выбора системного меню.
- Ошибки обновления отображаются отдельно от состояния авторизации; отсутствие квоты не превращается в подтверждённый полный или исчерпанный остаток.

<a id="delivery"></a>
## Установка, обновления и публикация

- Подготовка и публикация проверены 21 standalone test на синтетическом payload и mock API.
- Установщик работает в области текущего пользователя. Подготовка и перезапуск приложения не требуют принудительного запуска от имени администратора.
- Подготовка установщика проверяет актуальность payload, корректно обрабатывает ошибки и ограничивает ожидание вспомогательного окна.
- Проверка GitHub Releases ограничивает время получения заголовков и тела ответа. После сетевого зависания можно выполнить новую проверку.
- Publisher сначала создаёт draft, проверяет установщик, portable, SHA256SUMS, `latest.yml` и blockmap, затем сверяет SHA-256 digest загруженных assets.
- Публикация привязана к точному Git HEAD. Уже опубликованный релиз не перезаписывается; окончательная публикация нового draft выполняется после проверки полного набора assets.
- Release notes берутся из файла текущей версии. Token используется внутри Node HTTP headers, без передачи через строку команды curl и без вывода в журнал.

- После branded-сборки финализатор проверяет соответствие payload текущей версии и build output, создаёт отдельный gzip blockmap без изменения установщика, пересчитывает SHA-512/size для `latest.yml` и SHA-256 для четырёх payload/metadata файлов.
