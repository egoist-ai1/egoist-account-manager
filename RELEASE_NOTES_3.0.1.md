# Codex Account Manager 3.0.1

Исправляющий локальный Windows-релиз для реального переключения аккаунтов Codex Desktop.

## Исправлено

- Текущая глобальная авторизация автоматически сопоставляется с сохранённым профилем по fingerprint или устойчивой паре provider/workspace.
- Устаревшая отметка активного аккаунта больше не блокирует следующее переключение.
- Отсутствие глобального `auth.json` считается signed-out состоянием, а не фатальной ошибкой.
- Ложный `drifted`, созданный из-за рассинхронизации active marker, очищается без перезаписи стабильного vault другого профиля.
- По умолчанию включено автоматическое закрытие: сначала мягкое, затем — только для повторно проверенного дерева процессов выбранного AppX-пакета.
- В дерево включаются helper-процессы Codex; внешние дочерние процессы за пределами package install root не завершаются.
- Причина ошибки переключения показывается пользователю и попадает в redacted-журнал.

## Проверка

- 61 test files / 278 tests.
- Реальная read-only диагностика установленного Codex 26.721.4979.0 обнаруживает один root и 10 точных package-процессов, включая `codex-code-mode-host.exe`.

Релиз остаётся локальным/manual до Authenticode-подписи и clean-VM проверки.
