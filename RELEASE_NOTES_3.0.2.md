# Codex Account Manager 3.0.2

Локальный Windows-релиз с безопасным переключением без риска завершить сам Manager вместе с Codex.

## Исправлено

- Перед закрытием Codex Manager проверяет всю цепочку собственных родительских процессов.
- Если Manager был открыт изнутри Codex, операция останавливается до записи `auth.json`; текущая авторизация остаётся целой.
- Интерфейс объясняет, что достаточно закрыть только Manager и открыть его из меню «Пуск» или с ярлыка.
- Незавершённая операция на фазе `quiescing` отменяется штатным startup recovery без изменения активного профиля.

## Проверка

- Stale active marker и реальная глобальная сессия согласуются до переключения.
- Signed-out состояние без `auth.json` не блокирует активацию сохранённого профиля.
- Ложный drift очищается только при точном совпадении fingerprint.
- Изолированный нативный Windows E2E завершает и повторно запускает синтетическое root/helper-дерево; установленный Codex в тесте не используется.
- Отдельно проверены rollback, crash recovery, concurrent lock и 1000-switch soak.
- Полный Node gate: 62 test files / 280 tests.

Релиз остаётся локальным/manual до Authenticode-подписи и clean-VM проверки.
