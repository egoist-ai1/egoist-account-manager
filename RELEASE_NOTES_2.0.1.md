# Codex Account Manager 2.0.1

- Исправлено обновление лимитов для профиля с устаревшим локальным `auth.json`.
- Если глобальная сессия Codex авторизована и email совпадает с сохранённым профилем, приложение безопасно восстанавливает только этот профиль и повторяет запрос лимитов.
- Если совпадения нет, интерфейс показывает «нужен вход» вместо общей ошибки; автообновление не повторяет бесполезные запросы до переавторизации.
