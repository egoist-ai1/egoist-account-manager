# Журнал изменений

## 3.1.6 - 2026-08-06

- Overview выбирает ближайший будущий reset по всем защищённым неархивным Codex-профилям и показывает точное время, источник, свежесть и coverage без ложного «через 7 дней».
- Accounts показывает честный общий размер набора, прокручивает 10+ профилей, поддерживает карточки и компактный список, а также сохраняемую ручную сортировку.
- Smart-order детерминирован: активный профиль, готовность, мощность подписки, остаток, ближайший reset, свежесть и стабильный Unicode/id tie-break.
- Antigravity визуально обесцвечен, отключён и объясняет состояние подсказкой «В разработке»; rail, Enter и command palette не уводят из основного Codex-контура.
- Доведены типографика, плотность, состояния focus/hover и адаптивная геометрия Overview, Accounts, Activity и Settings без изменения vault/auth/switch-протокола.
- Добавлен секрет-безопасный live Windows Sandbox E2E: штатный зашифрованный импорт двух неактивных профилей, обновление 3.1.5 → 3.1.6 и три проверяемых перезапуска Codex с redacted-оракулом.
- Sandbox helpers передают результат через атомарные JSON-отчёты и самодостаточный staged runtime; GUI Electron stdout больше не может создать ложный отказ.
- Непрерывный 1000-switch soak разбит на 10 наблюдаемых пакетов в одной БД, чтобы медленный GitHub runner не пересекал внутренний RPC-watchdog Vitest.

## 3.1.5 - 2026-08-03

- Исправлена воспроизведённая по журналу гонка `prepare → reauth → switch`: отклонённое переключение больше не оставляет singleton-транзакцию активной до перезапуска приложения.
- Подготовленная транзакция гарантированно завершается при незавершённой авторизации целевого профиля, занятом межпроцессном lock или другом отказе до записи `auth.json`.
- Повторный запуск reauth для одного профиля безопасно закрывает предыдущий временный app-server и удаляет его manager-owned профиль, исключая скрытые 15-минутные блокировки.
- Reauth другого аккаунта больше не блокирует переключение готового целевого профиля; сериализация сохранения credentials и switch остаётся на provider-lock.
- После подтверждённого commit карточки сразу получают новый активный профиль, а фоновый reload больше не удерживает кнопку «Переключить»; активное действие имеет корректный pointer-state.
- Добавлены регрессии target reauth, race after preparation, duplicate reauth и cross-process rejection; полный Node gate содержит 343+ теста и 1000-switch soak.

## 3.1.0 - 2026-08-02

- Удалён экспериментальный импорт «Текущий Codex» и произвольного `auth.json`: публичный мастер оставляет только официальные входы Codex через браузер, device code, API key и Enterprise access token.
- Сохранённая авторизация стала устойчивее к кратковременному выходу Codex Desktop: Manager использует собственный DPAPI-vault и стабильное двукратное чтение `auth.json`, не перезаписывая последний корректный снимок частично записанным файлом.
- Переключение сохраняет проверяемую цепочку `подготовка → применение → запуск → identity verification` с транзакционным commit/rollback; автоматические тесты не закрывают и не переавторизуют установленный Codex.
- SQLite-схема обновлена до v10: восстановлен single-active invariant, добавлен уникальный partial index, индексы горячих запросов, `WAL`, `synchronous=FULL`, bounded timeout и безопасный `PRAGMA optimize`.
- Проверка обновлений выполняется при старте через фиксированный GitHub Releases API проекта. При наличии новой стабильной версии приложение показывает уведомление и открывает только allowlisted страницу релиза; скрытая загрузка и запуск EXE исключены.
- `electron-updater` удалён из runtime и lockfile. Ошибки фоновой проверки не растягивают интерфейс; ручная проверка сохраняет понятное диагностическое сообщение.
- Добавлены фирменное уведомление о новой версии, дедупликация, строгий semver, 20-секундный timeout, ограничение размера ответа и регрессии для подменённой release URL.
- Build-контур теперь очищает `dist` перед компиляцией, а package verifier отклоняет orphan content-hash bundles; финальный ASAR содержит только два entry assets, на которые ссылается `index.html`.
- Финальный gate: 69 файлов / 323 теста, 11/11 активных Chromium smoke, 76/76 ASAR parity, изолированный packaged startup и 0 известных dependency vulnerabilities.

## 3.0.10 - 2026-08-02

- Исправлена первопричина пустого нижнего ряда и вертикального скролла Overview: условный update-banner больше не резервирует grid-строку, а рабочая область растягивается до нижнего padding окна.
- Стандартный `1460×900` Overview измерительно помещается целиком: без page-scroll, клиппинга нижних карточек и скрытого footer; компактный режим сохраняет адаптивный поток.
- Последняя операция объясняет проверенный маршрут `DPAPI snapshot → точный перезапуск Codex → identity verification`, а не только показывает итоговый статус.
- В основном мастере добавлены «Текущий Codex» и «Выбрать auth.json». File-backed текущая сессия считывается из effective `CODEX_HOME`, проверяется через официальный app-server, сохраняет полученные лимиты и сразу шифруется в DPAPI-vault.
- Импорт `auth.json` теперь принимает только обычный файл до 1 MiB, отклоняет ссылки/каталоги и изменяющийся во время чтения файл, проверяет JSON-object и запускает app-server без forced token refresh.
- `keyring`, `auto` и `ephemeral` показываются как linked-only/needs-login: Manager не извлекает Windows credentials и не меняет пользовательский `config.toml`.
- Antigravity onboarding показывает три основных сценария без скрытия: Google OAuth, обнаруженный локальный IDE-профиль и JSON; редкие источники перенесены в восстановление.
- In-app notice получил подписанные этапы, а Windows toast — фирменную attribution-строку, круглую иконку и кнопку открытия Manager. Добавлены отдельные уведомления об импорте текущей сессии и `auth.json`.
- Добавлены unit и Chromium-регрессии для current-session import, keyring fail-closed, size cap, branded toast actions, мастера входа и вертикальной геометрии Overview.
